04 / الإدخال والإخراج

print() و input()

print() تعرض النتيجة على الشاشة. input() تستنى المستخدم يكتب قيمة ويضغط Enter. الفاصلة داخل print تجمع نص وقيمة مع بعض.

name = input("Enter your name: ")
x = 7
y = 3
print("Sum:", x + y)Sum: 10
05 / تحويل الأنواع

أشهر فخ في الكويز

الدالة input() ترجّع نص دايمًا. فلو جمعت رقمين من غير تحويل، هيتلزقوا جنب بعض.

x = input("First: ")     # 5
y = input("Second: ")    # 7
print(x + y)57
x = int(input("First: "))
y = int(input("Second: "))
print(x + y)12

استخدم int() للأعداد الصحيحة و float() للأعداد العشرية. وتقدر تدخل أكتر من رقم بفاصلة باستخدام eval(input()).

06 / الشروط

if / elif / else

البرنامج بيسأل سؤال إجابته True أو False، وينفّذ أول شرط يتحقق بس. لازم علامة : بعد الشرط، ومسافة بادئة للأوامر اللي جواه. وتذكّر: == للمقارنة و = للتخزين.

number = 8
if number % 2 == 0:
    print("Even")
else:
    print("Odd")Even
07 / التكرار (while)

كرّر طول ما الشرط صح

استخدمها لما متعرفش عدد اللفات مسبقًا. حدّد العداد قبل الـ loop، وحدّثه جواها. لو نسيت التحديث هتحصل infinite loop.

number = 1
while number <= 5:
    print(number)
    number = number + 11 2 3 4 5
08 / التكرار (for)

for و range()

استخدمها لما عدد اللفات معروف. الشكل: range(start, stop, step)، والـ stop مش داخل في الأرقام.

range(3)0, 1, 2
range(1, 6)1 … 5
range(5, 0, -1)5 … 1
for count in range(3):
    print("Hello")Hello ×3
09 / مثال تطبيقي

جمع المبيعات (Accumulation)

ابدأ المجموع بصفر، وفي كل لفة أضف القيمة الجديدة على المجموع القديم. ولو كتبت total = value هتمسح اللي قبلها.

total_sales = 0
for day in range(1, 4):
    sales = float(input("Enter sales: "))
    total_sales = total_sales + sales
print("Total sales:", total_sales)100, 200, 300 → 600.0
